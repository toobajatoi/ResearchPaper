# How Do Language Models Sound Human?

Scoping review of anthropomorphic communication cues in large language model output, with an agenda for cross-lingual research.

The manuscript draft is `SCOPING_REVIEW/HMC_submission_draft.md`. Searches were run on 29 September 2026. The screening file holds 2,910 records. Sixty-nine sources meet the inclusion criteria. Twenty-two reports were not retrieved.

Screening decisions were drafted by an AI coding agent. The author checked the 69 included studies. Exclusions were checked against their recorded reasons by the same agent in a second pass. That pass is not an independent verification, and no second human reviewer screened the records.
